# 02 对话定级多邻国（Duolingo）多屏流与 AI 伴读智能重构方案

## 1. 核心设计目标与参考对照
结合用户提供的多邻国 4 张官方设计参考图与澄清选项，解决当前「全部交互堆叠在一个长聊天框、信息密度过大、缺少独立分屏节奏」的问题：
- **单屏单任务（One Screen, One Focus）**：从兴趣星盘完成之后，进入纯粹的 Duolingo 多屏交互流，每一屏仅呈现一道问题或一个句子。
- **伴读角色与智能气泡（AI Companion & Dynamic Reasoning Bubble）**：
  - 屏幕顶部呈现小灯伴读角色与对话气泡（参照多邻国多儿猫头鹰持笔记本/比划的经典排布）。
  - **AI 智能化亮点**：用户点击选项卡时，小灯气泡**立即进行智能分析与鼓励**（如点击「升学备考」即时反馈：「🎯 靶向备考！我们将精准匹配真题长难句与高频考点语料」），彻底告别死板的静态表单。
- **Duolingo 质感选项卡与底部「继续」操作条（Bottom Continue CTA）**：
  - 选项采用 Duolingo 经典质感卡片：大圆角（`rounded-2xl`）、微厚边框、点击微弹性（`active:scale-[0.98]`）、推荐角标（`RECOMMENDED`）。
  - 底部常驻固定的主操作栏与「继续 / Continue」按钮：未选择时为浅灰禁用态，选中并获得 AI 反馈后高亮激活，点击进入下一屏。
- **语感试读 4 句多屏评测**：
  - 独立的试读大卡片（含发音图标、句子排版、CEFR 阶梯标识）。
  - 三档质感评测卡（稍显吃力 / 刚刚好·推荐 / 轻松有余）。
  - 点击后小灯即时给出动态诊断反馈（Live Diagnostic Feedback），点击底部继续前往下一句。

## 2. 多屏全流程分步架构

```
[星盘探索屏]
    │ (点击：兴趣星盘已就绪)
    ▼
[多屏准备引导屏 (Intro)]
    │ 小灯在中央挥手 + "先了解你的 5 个阅读习惯，再开始 4 句轻试读！"
    │ 底部大绿色/金黄色「开始 / Continue」按钮
    ▼
[习惯调研分屏 Q1~Q5 (Habit Profiling)]
    │ 顶部：返回箭头 + 全宽进度条 (从 10% 渐进到 55%)
    │ 上部：小灯角色 + 气泡 (初显题目，选中时显示智能推演)
    │ 中部：Duolingo 质感选项卡 (Q1 目标 ➔ Q2 专项 ➔ Q3 瓶颈 ➔ Q4 时长 ➔ Q5 伴读)
    │ 底部：固定「继续 / Continue」按钮 (选中点亮)
    ▼
[4 句语感自适应试读分屏 S1~S4 (Reading Assessment)]
    │ 顶部：返回箭头 + 全宽进度条 (从 60% 渐进到 95%)
    │ 上部：小灯气泡 (提示品读重点 / 实时难度诊断)
    │ 中部：精致英文原句阅读卡片 + 语音朗读 + 三档触感选择卡
    │ 底部：固定「继续」按钮
    ▼
[定级达成屏 (Placement Complete)]
    │ 小灯祝贺动效 + 建议起点 CEFR 大徽章 + 习惯画像总结
    │ 底部大按钮：「开启专属定制世界」
```

## 3. 界面细节与组件规范

### 1) 顶部导航与进度指示器（Top Header & Smooth Progress Bar）
- 顶部保留左侧返回箭头（`ArrowLeft`），点击可平滑返回上一屏或上一题。
- 贯穿式胶囊进度条（`h-3.5 rounded-full bg-[#E5E0D5]` 内嵌平滑渐变的高亮进度条 `transition-all duration-400 ease-out`）。
- 右侧保留极简的步骤提示（如 `1/9`、`2/9`）。

### 2) 伴读角色与对话气泡（Companion & Speech Bubble）
- 依据多邻国设计（Image 2, 3, 4）：
  - 左侧：小灯伴读形象（圆形发光或角色全身像，携带微动效）。
  - 右侧：带有指向小尾巴的圆角对话气泡（`rounded-2xl border-2 border-[#E5E0D5] bg-white p-3.5 shadow-sm`）。
  - **交互动效**：当用户切换不同选项时，气泡文字带微动效无缝切换为该选项的专属 AI 智能化解析，给用户「AI 在深度理解我的选择」的即时正向反馈。

### 3) 选项卡片设计（Duolingo Option Cards）
- 遵循多邻国标准卡片规范：
  - 布局：纵向列表或双列均衡卡片，外框采用 `border-2`，未选中为纯白或浅米白。
  - 选中态：金琥珀/明亮绿边框、柔和背景微光、右侧显示选中状态标记。
  - 推荐标识：在重点推荐项（如「刚刚好，顺畅适中」或「中高考拔高」）右上角悬浮小巧的 `RECOMMENDED` 鲜明角标（参考 Image 3 & 4）。

### 4) 底部常驻按钮（Sticky Bottom Action Button）
- 底部固定区域（`p-4 bg-white/95 border-t border-[#E8DFC8]`）。
- 按钮：全宽大圆角按钮（`h-13 rounded-2xl font-bold text-base shadow-sm`）。
  - 未选状态：`bg-stone-200 text-stone-400 cursor-not-allowed`。
  - 激活状态：温润金黄/翡翠绿渐变，具有立体按压反馈（`active:translate-y-0.5 active:shadow-none`）。

## 4. 技术实施计划

1. **状态机与分步数据驱动重构**：
   - 统一梳理步骤序号：
     - Step 1: 兴趣星盘
     - Step 2: 引导过渡屏（参考 Image 1）
     - Step 11: Q1 核心目标
     - Step 12: Q2 重点场景（中考、高考、四六级、考研、雅思、PET/KET；跨境电商、外刊等分支）
     - Step 15: Q3 攻坚瓶颈
     - Step 13: Q4 专注节奏
     - Step 14: Q5 伴读风格
     - Step 3~6: 4 句自适应语感定级试读
     - Step 7: 最终定级达成页
2. **AI 智能即时推理映射表**：
   - 为每个选项配置预生成的即时 AI 推理反馈文案（`aiReasoning`），用户点击时立即打在小灯气泡中，避免重复等待接口。
3. **视觉与交互重塑**：
   - 编写 `DuolingoProgressHeader`、`CompanionBubblePrompt`、`DuolingoOptionCard`、`StickyContinueBar`。
4. **编译与验证**：执行 `compile_applet` 和 `lint_applet`，确保零警告零报错，平稳运行。
