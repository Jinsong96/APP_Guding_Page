# 第二页（Stage 02）多屏网格系统与极简交互重构方案

## 1. 核心设计背景与目标
针对当前第二页出现的「信息密集堆叠、长列表滚动负担重、视觉层次单一」等痛点，依据用户反馈与澄清选项：
- **单屏专注架构**：从传统的长对话历史流，升级为**多屏分步卡片交互（Multi-Screen Step Experience）**，每一屏仅聚焦当前单一任务（星盘兴趣 ➔ 调研问卷 Q1~Q5 ➔ 句子试读 1~4 ➔ 定级报告）。
- **紧凑伴读气泡 + 步骤看板**：卡片顶部配备紧凑的小灯伴读动态提示与极简进度指示器（Progress Dots / Step Counter），保持趣味互动与亲切感。
- **Bento Grid 双列网格**：习惯问卷选项采用均衡的 2 列便当盒（Bento Grid）网格排版，运用通用符号（Universal Symbols）替代冗余冗长表述，重点信息明确突出。
- **质感试读卡与三档触感按键**：句子测试界面突出核心英文原句与 CEFR 标识，底部提供 3 档极简触感反馈按键（吃力 / 舒适 / 轻松），节奏张弛有度。

---

## 2. 界面与交互重构方案

### 屏 1：星盘兴趣定制屏（Galaxy Compass）
- 保持原有的星盘转动与 6 大兴趣标签选择，界面顶部精简，去掉底部聊天流堆积。
- 点击「生成专属阅读方案」后，平滑过渡到问卷第一屏。

### 屏 2 ~ 屏 6：习惯调研分屏（Q1 ~ Q5 Bento Grid）
每一问独占一屏，采用统一的卡片网格系统：
- **顶部 Header**：
  - 进度指示：极简点状进度线（`01 / 05`）与分类标签（如「核心目标」「重点场景」）。
  - 伴读指引：小灯伴读微头像 + 紧凑单行气泡（包含打字动效或微光光晕）。
  - 返回操作：右上角轻量「上一题」与「重选星盘」按钮。
- **中部主体（Bento Grid 网格）**：
  - 采用 2 列自适应网格（`grid grid-cols-1 sm:grid-cols-2 gap-3`），卡片高度匀称。
  - **视觉层次**：
    - 大图标 / 通用符号（🎯、💼、🌟、🌱 等）作为视觉锚点。
    - 关键标题字号加粗（15px），辅以纯净深灰（`text-stone-900`）。
    - 辅助说明提炼为简短精炼的一句话，弱化为次级灰色（`text-stone-500 text-xs`）。
    - 选中态：金琥珀色高光边框、微光浅黄底色、右上角精致勾选符。
- **节奏过渡**：
  - 点击选项后立即触发优雅的平滑换屏过渡，无需用户翻滚屏幕。

### 屏 7 ~ 屏 10：四句试读与自适应评测屏（Sentence Assessment 1 ~ 4）
- **核心试读卡片**：
  - 顶部醒目标注试读进度（`Sentence 01 of 04`）与当前动态阶梯（如 `A2 Foundation`）。
  - 纯净排版区域：精美衬线/无衬线高可读性大字排版（`font-serif` 或清晰英文字体），突出重点词汇与语法韵律。
  - 发音辅助与静心阅读缓冲（2 秒专属静读动画指示）。
- **底部三档触感按键（Tactile Buttons）**：
  - 采用并排或三等分网格布局：
    1. 🔴 **稍显吃力**（Down / 降级降速）
    2. 🟢 **舒适顺畅**（Keep / 契合节奏，重点突出推荐）
    3. 🔵 **挑战进阶**（Up / 轻松拔高）
  - 按钮具备物理触感阴影、点击微弹反馈，支持返回上一句修改。

### 屏 11：定级生成与过渡展示屏
- 测验完成后直观展示测定等级卡片（CEFR 评级、雷达简图、个人画像速览），配合小灯伴读祝贺语，引导进入下一阶段。

## 3. 设计规范与技术细节
- **网格规范**：
  - 外层容器：居中固定最大宽度卡片（`max-w-2xl`），四周留白呼吸感充足。
  - 间距节奏：统一遵循 4px/8px 倍数（`p-5 sm:p-7`, `gap-3`）。
- **配色与质感**：
  - 主基调延续温润纸感（`#FAF6ED`），卡片背景采用高纯白（`#FFFFFF`）配合极细边框（`#E7DFD0`）与柔和阴影。
  - 强调色延续星盘亮黄与琥珀金（`#F59E0B`、`#D97706`），避免大面积重色块。
- **国际化极简表现**：
  - 减少说教式长文本，采用直观图标符号、进度圆点、层级标牌（Pills & Badges）。

## 4. 实施计划与步骤
1. **重构 `Stage02AiChat.tsx` 视图渲染结构**：
   - 将原先单一的聊天气泡纵向消息列表改为「单屏聚焦卡片模式（Step Card）」。
   - 构建 `SurveyStepView`：负责 Q1~Q5 的 2 列 Bento Grid 渲染。
   - 构建 `SentenceStepView`：负责 4 句试读的高可读性句子卡片与 3 档触感按键。
2. **状态与导航逻辑适配**：
   - 保留原有的全部动态分支题库（中考、KET、PET、跨境电商、外刊阅读等）与 CEFR 定级算法。
   - 优化步进状态机与「上一题/上一句」平滑回退体验。
3. **视觉微调与动效校验**：
   - 确保卡片间切换无跳跃、无多余滚动条，在移动端与桌面端均具备卓越的排版美感。
4. **编译与验证**：执行 `compile_applet` 和 `lint_applet` 确保零错误。
